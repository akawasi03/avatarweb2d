## Chú ý kỹ thuật

### Layer system
Mỗi map có nhiều layer chồng lên nhau:
- `layer_0.png` = nền chính (ground)
- `layer_1.png`, `layer_2.png` = các lớp phía trên (objects, overlay)
- `layer_daydien0.png` = hiệu ứng ban đêm (đèn, ánh sáng)

### Chất lượng
- `HD/` — độ phân giải cao (gấp đôi Medium)
- `Medium/` — độ phân giải thấp hơn (mobile/low-spec)
